# FlossKeeper

FlossKeeper is a simple free and open-source desktop app for tracking your cross-stitch floss collection.

It lets you track which DMC colors you own, whether they are stored as bobbins or skeins, and helps you figure out which colors you still need for a pattern.

## Features

- Track DMC floss colors
- Track bobbins and skeins separately
- Search your floss collection
- Generate missing-color lists
- Copy need-to-buy lists
- Backup and restore your stash
- Export your collection as TSV
- Pattern Planner tab for checking pattern requirements against your stash
- Storage / Sync tab
- Custom stash file location support
- Works with synced stash files through Syncthing, Dropbox, Google Drive tools, SMB shares, or any local synced folder
- Light and dark theme support
- About screen
- First-run help
- Help button
- Available for Linux and Windows

## v1.4.0 Highlights

- Added stash path persistence so the selected stash file is remembered after closing and reopening.

### Improved

- Backup / Restore now respects the custom stash file location.
- Added sync conflict warning area in the Storage / Sync tab.
- Windows installer updated for v1.4.0.

### Tested

- Linux AppImage tested on Chaos.
- Windows executable tested on Mana.
- Windows installer tested on Mana.
- Syncthing sync tested between Chaos, Omega, and Mana.

## Notes

FlossKeeper is built for personal floss inventory management and cross-stitch planning. It is lightweight, offline, and does not require an account.
